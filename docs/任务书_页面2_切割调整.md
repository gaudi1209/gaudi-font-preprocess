# 页面2：切割调整 (adjust.html)

## 功能概述

查看切割结果，按传统书法顺序排列，支持单字微调和删除。

## 核心功能

| 功能 | 描述 |
|------|------|
| 字符显示 | 网格布局，按传统书法顺序编号（从右到左、从上到下） |
| 空切片检测 | 边缘腐蚀+轮廓检测，文本框面积<5%视为空切片 |
| 状态标签 | 显示"需调整"（红色）和"已调整"（蓝色）标签 |
| 单字调整 | 可视化拖动边界框，调整上下左右边距 |
| 字符删除 | 右键点击删除不需要的字符 |
| 数据保存 | 调整结果绑定图片哈希值，保存到会话数据 |

## 算法逻辑

### 传统书法顺序算法

传统书法阅读顺序：**从上到下，从右到左**

```
排序逻辑:
1. strip_index 大的（右边的列）排在前面
2. 同一列内，char_index 小的（上面的）排在前面

实现:
characters.sort((a, b) => {
    if (a.strip_index !== b.strip_index) {
        return b.strip_index - a.strip_index;  // 右列优先
    }
    return a.char_index - b.char_index;  // 上行优先
})
```

### 空切片检测算法

```
输入: 切割后的字符图片
输出: (is_empty, text_ratio, boxes)

步骤:
1. 边缘腐蚀：使用3x3核进行形态学腐蚀，去除边缘噪点
2. 二值化：确保图片是黑白二值图
3. 轮廓检测：使用 cv2.findContours 找到文字区域
4. 过滤小轮廓：移除面积 < 图片面积*0.001 的噪声
5. 计算文本框总面积：所有轮廓的外接矩形面积之和
6. 计算文本占比：text_ratio = 文本框面积 / 图片面积
7. 判断：text_ratio < 5% 则为空切片
```

## 容易犯的错误

| 错误 | 描述 | 解决方案 |
|------|------|----------|
| **编号顺序错误** | 使用现代顺序（从左到右）而非传统顺序（从右到左） | 使用 strip_index 降序排序 |
| **图片异步加载竞态** | 快速切换不同字符时，显示的还是上一个字符 | 缓存图片对象到 canvasState.img |
| **选择状态未清除** | 关闭弹窗后再次选择，之前的选择仍然存在 | 关闭弹窗时清空 selectedIndices |
| **坐标数据丢失** | 从目录扫描的字符没有 x,y 坐标信息 | 检测坐标是否有效，无效则重新生成 |
| **Canvas坐标系统不匹配** | Canvas的CSS显示尺寸与内部尺寸(canvas.width/height)不一致，导致边界框右边和下边无法拖动 | 使用缩放比例转换坐标 |

### Canvas坐标转换示例代码

```javascript
// 将鼠标CSS坐标转换为Canvas内部坐标
function getCanvasCoords(e) {
    const canvas = e.target;
    const rect = canvas.getBoundingClientRect();

    // 计算缩放比例
    const scaleX = canvas.width / rect.width;
    const scaleY = canvas.height / rect.height;

    // 转换坐标
    const x = (e.clientX - rect.left) * scaleX;
    const y = (e.clientY - rect.top) * scaleY;

    return { x, y };
}
```

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 空切片阈值 | 5% (0.05) | 文本框面积占比低于此值为空切片 |
| 轮廓最小面积 | 0.1% (0.001) | 小于此值的轮廓视为噪声 |
| 边缘检测阈值 | 25-30px | 边界框拖动检测范围 |
| Canvas最大尺寸 | 500px | 调整弹窗中预览图最大尺寸 |
