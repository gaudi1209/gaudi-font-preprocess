# 页面3：缩放校正 (scale.html)

## 功能概述

对切割后的字符进行统一缩放和居中处理，生成512x512标准尺寸的字库素材。

## 核心功能

| 功能 | 描述 |
|------|------|
| 字符预览 | 网格布局，按传统书法顺序显示所有字符 |
| 自动居中 | 页面加载时自动进行默认参数的居中处理 |
| 缩放控制 | 滑块控制缩放比例（50%-150%，默认115%） |
| 对齐方式 | 支持居中、左对齐、右对齐三种水平对齐 |
| 背景色 | 支持黑色或透明背景 |
| 实时预览 | 处理后立即显示预览效果 |
| 结果保存 | 保存处理后的图片到scaled目录 |

---

## 算法逻辑

### 缩放居中算法

```
输入: 原始字符图片, 缩放比例, 对齐方式, 背景色, 目标尺寸
输出: 512x512 处理后的图片

步骤:
1. 读取原始字符图片
2. 按缩放比例缩放图片
3. 创建目标尺寸(512x512)的画布
4. 根据对齐方式计算放置位置:
   - center: x = (512 - scaled_width) / 2
   - left: x = 0
   - right: x = 512 - scaled_width
   - y 始终居中: y = (512 - scaled_height) / 2
5. 将缩放后的图片放置到画布上
6. 填充背景色（黑色或透明）
```

### 关键代码逻辑

```python
def process_character(img, scale, align, background, target_size):
    # 缩放
    new_width = int(img.shape[1] * scale)
    new_height = int(img.shape[0] * scale)
    scaled = cv2.resize(img, (new_width, new_height))

    # 创建目标画布
    if background == 'transparent':
        canvas = np.zeros((target_size, target_size, 4), dtype=np.uint8)
    else:
        canvas = np.zeros((target_size, target_size), dtype=np.uint8)

    # 计算放置位置
    if align == 'left':
        x_offset = 0
    elif align == 'right':
        x_offset = target_size - new_width
    else:  # center
        x_offset = (target_size - new_width) // 2

    y_offset = (target_size - new_height) // 2

    # 放置图片
    canvas[y_offset:y_offset+new_height, x_offset:x_offset+new_width] = scaled

    return canvas
```

## 容易犯的错误

| 错误 | 描述 | 解决方案 |
|------|------|----------|
| **整数类型错误** | OpenCV的切片索引必须是整数，使用浮点数会导致 `slice indices must be integers` 错误 | 所有计算结果使用 `int()` 显式转换 |
| **自动处理失败无反馈** | 页面加载时自动处理失败，用户不知道发生了什么 | 添加 try-catch，失败时显示原始预览并在控制台输出错误 |
| **处理参数未传递** | 前端未正确传递缩放比例等参数 | 检查请求体中的参数名称和格式 |
| **图片缓存问题** | 处理后刷新页面仍显示旧图片 | 在图片URL后添加时间戳参数 `?t=timestamp` |

### 整数转换示例代码

```python
# 错误：adjust_top 可能是浮点数
y1 = char['y'] + char['adjust_top']

# 正确：显式转换为整数
y1 = int(char['y'] + char.get('adjust_top', 0))
y2 = int(char['y'] + char['height'] - char.get('adjust_bottom', 0))
x1 = int(char['x'] + char.get('adjust_left', 0))
x2 = int(char['x'] + char['width'] - char.get('adjust_right', 0))
```

## API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/get_cut_results/<hash>` | GET | 获取切割结果（如果没有缩放结果） |
| `/api/process_scale` | POST | 处理缩放和居中 |
| `/api/save_scaled` | POST | 保存处理结果 |
| `/api/open_directory` | POST | 打开输出目录 |

### 请求/响应示例

**POST /api/process_scale**
```json
// 请求
{
  "hash": "图片哈希值",
  "characters": [...],
  "scale": 1.15,
  "align": "center",
  "background": "black",
  "target_size": 512
}

// 响应
{
  "success": true,
  "characters": [
    {
      "index": 0,
      "processed_url": "/output/<hash>/scaled/scaled_0000.png",
      "processed_filename": "scaled_0000.png"
    }
  ],
  "output_dir": "output/<hash>/scaled"
}
```

## 数据存储格式

缩放处理后的数据保存在会话JSON的 `scaled_characters` 字段中：

```json
{
  "hash": "图片MD5哈希值",
  "characters": [...],
  "scaled_characters": [
    {
      "index": 0,
      "original_filename": "char_0000.png",
      "processed_filename": "scaled_0000.png",
      "processed_url": "/output/<hash>/scaled/scaled_0000.png",
      "scale": 1.15,
      "align": "center"
    }
  ]
}
```

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 目标尺寸 | 512x512 | 字库素材标准尺寸 |
| 默认缩放 | 115% (1.15) | 使字符略大于画布，确保视觉饱满 |
| 缩放范围 | 50%-150% | 滑块可调节范围 |
| 默认对齐 | center | 水平居中对齐 |
| 默认背景 | black | 黑色背景 |
