# 页面1：切割布局 (layout.html)

## 功能概述

上传书法图片，自动/手动设置切割线，将整图切割成单个字符。

## 核心功能

| 功能 | 描述 |
|------|------|
| 图片上传 | 支持上传书法图片，自动二值化处理，锁定比例缩放到目标高度(4096px) |
| OCR识别 | 自动检测文本框位置，生成初始切割线（绿色虚线显示） |
| 竖向切割线 | 红色线条，Shift+双击添加，可拖动调整，Alt+点击删除 |
| 横向切割线 | 蓝色线条，双击添加到当前列，每列独立管理 |
| 缩放平移 | 鼠标滚轮缩放，右键拖动平移 |
| 数据持久化 | 切割线配置+文本框数据绑定图片哈希值，保存到JSON文件 |
| 应用切割 | 根据切割线切割图片，保存切割结果 |

## 交互设计

| 操作 | 效果 |

| 鼠标滚轮 | 缩放图片 |

## 切割线算法逻辑

### 竖向切割线算法

```
输入: OCR检测的文本框列表
输出: 竖向切割线x坐标数组

步骤:
1. 收集所有文本框的左右边界 x 坐标
2. 按 x 坐标排序
3. 计算相邻边界之间的间距
4. 找出间距的"跳变点"（间距突然增大的位置）
5. 在跳变点的中间位置设置竖向切割线
```

### 横向切割线算法（按列分组）

```
输入: 竖向切割线数组, OCR文本框列表
输出: 每列的横向切割线数组

步骤:
1. 根据竖向切割线将图片分成多个竖条（strip）
2. 对每个竖条:
   a. 筛选在该竖条范围内的文本框
   b. 收集文本框的上下边界 y 坐标
   c. 计算相邻文本框之间的间距
   d. 在间距中间位置设置横向切割线
3. 返回 strip_horizontal_lines 结构
```

### 列结构更新算法

当竖向切割线变化（新增或删除）时，需要更新列结构：

```
输入: 新的竖向切割线数组, 旧的列结构
输出: 新的列结构

新增竖向切割线:
- 新列继承原列的所有横向切割线

删除竖向切割线:
- 合并后的列合并所有相关列的横向切割线（去重）

关键逻辑:
for (每个新列) {
    mergedHLines = {0, imageHeight}  // 始终包含边界
    for (每个旧列) {
        if (旧列与新列有重叠) {
            合并该旧列的所有横向切割线
        }
    }
    新列.horizontal_lines = sorted(mergedHLines)
}
```

数据结构:
```json
{
  "strip_horizontal_lines": [
    {
      "strip_index": 0,
      "x_start": 0,
      "x_end": 500,
      "horizontal_lines": [0, 100, 200, 300, 400]
    },
    {
      "strip_index": 1,
      "x_start": 500,
      "x_end": 1000,
      "horizontal_lines": [0, 80, 180, 280, 380]
    }
  ]
}
```

## 容易犯的错误

| 错误 | 描述 | 解决方案 |
|------|------|----------|
| **全局横向切割线** | 用整张图片的所有文本框计算横向切割线，导致不同列的字无法对齐 | 改为**按列分组**，每列独立计算横向切割线 |
| **横向切割线跨列** | 添加横线时应用到所有列，导致跨行切割 | 只添加到**双击所在的列** |
| **删除竖线丢失横线** | 删除竖向切割线时，只继承一个列的横线，丢失其他列的横线 | **合并所有重叠列**的横向切割线 |
| **文本框消失** | 保存切割线时未保存boxes数据，再次加载时文本框丢失 | 保存时**同时保存boxes**，加载时恢复 |
| **间距阈值固定** | 使用固定像素值判断列分界，不同分辨率图片效果差异大 | 使用**相对阈值**（如平均间距的2倍） |
| **边界溢出** | 切割线坐标超出图片范围，导致数组越界 | 添加边界检查，确保坐标在范围内 |
| **首尾切割线缺失** | 忘记添加图片边缘作为首尾切割线 | 强制添加 `x=0`, `x=width`, `y=0`, `y=height` |

## API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/upload` | POST | 上传图片并预处理，返回切割线和文本框 |
| `/api/save_cuts` | POST | 保存切割线配置（含boxes） |
| `/api/load_session/<hash>` | GET | 加载会话数据 |
| `/api/apply_cuts` | POST | 应用切割 |

## 调试技巧

1. **可视化切割线**: 在Canvas上用不同颜色绘制竖向(红)和横向(蓝)切割线
2. **控制台日志**: 添加横线或更新列结构时打印详细日志
3. **分步验证**: 先验证竖向切割线是否正确分列，再验证每列的横向切割线
4. **边界情况测试**: 测试单列、单行、空图片等极端情况
