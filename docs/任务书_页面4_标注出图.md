# 页面4：标注出图 (annotate.html)

## 功能概述

为切割后的字符标注繁简体信息，导出白底黑字的字库素材图片，支持FontLab CSV格式导出。

## 核心功能

| 功能 | 描述 |
|------|------|
| 目录导入 | 支持导入已有字符图片目录 |
| 繁简转换 | 输入简体自动转繁体，输入繁体自动转简体 |
| 模式切换 | "以简为主"和"以繁为主"两种模式，决定导出时使用哪个字 |
| 批量标注 | 输入文字后自动按顺序填充到卡片 |
| UTF编码显示 | 实时显示字符的Unicode编码（U+XXXX格式） |
| 白底黑字导出 | 反色处理，导出适合字库使用的白底黑字图片 |
| FontLab CSV | 导出FontLab软件可用的CSV标注文件 |
| 重复字处理 | 相同字符自动添加_01、_02后缀 |

## 算法逻辑

### 繁简转换

使用 OpenCC 库进行繁简转换：

```python
import opencc

# 简体转繁体
converter = opencc.OpenCC('s2t')
traditional = converter.convert(simplified)

# 繁体转简体
converter = opencc.OpenCC('t2s')
simplified = converter.convert(traditional)
```

### UTF编码生成

```javascript
function getUtfCode(char) {
    const code = char.charCodeAt(0);
    return 'U+' + code.toString(16).toUpperCase().padStart(4, '0');
}
// 例：'天' -> 'U+5929'
```

### 重复字后缀处理

```python
char_counts = {}
for ann in annotations:
    char = ann.get('character', '')

    if char in char_counts:
        char_counts[char] += 1
        suffix = f"_{char_counts[char]:02d}"  # _01, _02, ...
    else:
        char_counts[char] = 0
        suffix = ""

    filename = f"uni{ord(char):04X}{suffix}.png"
    # 例：第一个"天" -> uni5929.png
    #     第二个"天" -> uni5929_01.png
```

### 图片反色处理

```python
# 黑底白字 -> 白底黑字
inverted = cv2.bitwise_not(img)
```

## 容易犯的错误

| 错误 | 描述 | 解决方案 |
|------|------|----------|
| **OpenCC配置路径错误** | 使用 `opencc.OpenCC('s2t.json')` 报错找不到配置文件 | 使用不带扩展名的配置名：`opencc.OpenCC('s2t')` |
| **cv2未导入** | 导出时 `cv2.bitwise_not` 报错 `name 'cv2' is not defined` | 在app.py顶部添加 `import cv2` |
| **输入循环更新** | 简体输入触发繁体更新，繁体更新又触发简体更新，造成循环 | 使用 `isUpdating` 标志防止循环 |
| **防抖未分离** | 简体和繁体共用一个防抖定时器，导致切换时冲突 | 为简体和繁体分别创建 `simpDebounceTimer` 和 `tradDebounceTimer` |
| **全局CSS覆盖** | `style.css` 中 `.char-card` 设置了 `aspect-ratio: 1`，导致卡片变成正方形，标注区域被裁剪 | 使用 `aspect-ratio: auto !important` 覆盖 |
| **标点符号干扰** | 输入的标点符号被当作字符处理 | 使用正则过滤：`text.replace(/[^\u4e00-\u9fa5a-zA-Z0-9]/g, '')` |

### 防抖+防循环示例代码

```javascript
let simpDebounceTimer;
let tradDebounceTimer;
let isUpdating = false;

elements.simplifiedInput.addEventListener('input', (e) => {
    if (isUpdating) return;  // 防止循环

    clearTimeout(simpDebounceTimer);
    simpDebounceTimer = setTimeout(async () => {
        const cleaned = removePunctuation(e.target.value);
        if (cleaned) {
            const result = await callConvertApi('/api/convert_to_traditional', cleaned);
            if (result) {
                isUpdating = true;
                elements.traditionalInput.value = result;
                setTimeout(() => isUpdating = false, 50);
            }
        }
    }, 300);
});
```

## API接口

| 接口 | 方法 | 描述 |
|------|------|------|
| `/api/convert_to_traditional` | POST | 简体转繁体 |
| `/api/convert_to_simplified` | POST | 繁体转简体 |
| `/api/get_scaled_results/<hash>` | GET | 获取缩放后的字符 |
| `/api/import_characters` | POST | 导入目录中的字符 |
| `/api/export_annotated` | POST | 导出白底黑字图片 |
| `/api/export_csv` | POST | 导出FontLab CSV |
| `/api/open_directory` | POST | 打开输出目录 |

### 请求/响应示例

**POST /api/convert_to_traditional**
```json
// 请求
{ "text": "中国" }

// 响应
{ "success": true, "result": "中國" }
```

**POST /api/export_annotated**
```json
// 请求
{
  "hash": "图片哈希值",
  "annotations": [
    {
      "index": 0,
      "filename": "scaled_0000.png",
      "character": "天",
      "simplified": "天",
      "traditional": "天"
    }
  ],
  "mode": "traditional"
}

// 响应
{
  "success": true,
  "count": 42,
  "output_dir": "output/<hash>/exported/20240101_120000"
}
```

## 导出文件格式

### 图片命名规则

```
uniXXXX.png       # 第一个相同字
uniXXXX_01.png    # 第二个相同字
uniXXXX_02.png    # 第三个相同字
...
```

示例：
- `uni5929.png` - 第一个"天"
- `uni5929_01.png` - 第二个"天"
- `uni4E2D.png` - "中"

### FontLab CSV格式

```csv
filename,unicode,simplified,traditional
uni5929.png,U+5929,天,天
uni4E2D.png,U+4E2D,中,中
uni570B.png,U+570B,国,國
```

## 关键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 防抖延迟 | 300ms | 输入停止后等待时间再触发转换 |
| UTF编码格式 | U+XXXX | 4位十六进制大写 |
| 默认模式 | 以繁为主 | 书法字库通常使用繁体 |
| 图片格式 | PNG | 无损格式，适合字库 |
