# 高迪书法字库预处理工具

> 数字时代，风格从字库开始。

## 开发初衷

这是一个为书法爱好者制作手写字体的软件。2018 年，我跟风一款手机 App，耗时 2 个月完成了 GB2312 书法字库。后来接触专业字库软件，发现手机 APP 制作的字库精度很低，对书法字体损失很大，也难以继续迭代改进。网上的 Python 改进方案操作繁琐，不符合书法爱好者的使用习惯。

## 书法爱好者做字库的痛点

1. 手写按规范填格枯燥漫长，日常习惯是写长篇作品，更适合日积月累创作；
2. 爱好者书写质量不稳定，需自由筛选优质字迹；
3. 手写长篇作品可作为字库素材，但预处理、人工编辑流程极繁琐。

## 高迪行书字库开发困境

实际制作高迪行书字库时，发现新难题：

1. 古典书法素材以繁体字为主，有效字符少（如《集王圣教序》仅 700 多不重复字），而港台一级繁体库（4800 字）和 GB2312（6700 字），多数字仍需手写。需要软件输出所需文本。
2. 手写近万字后，覆盖 GB2312、港台一级繁体库，满足日常 99.9% 需求，但仍有零星生僻字缺失，影响最终效果。

## AI 字体工具的诞生与局限

为补全生僻字，基于开源项目 zi2zi 开发**[高迪书法字库 AI 字体工具](https://github.com/gaudi1209/ai-font-tool)**：

1. 功能：导入缺失字符文本、训练万字基础模型、生成生僻字、OCR 校验筛选；
2. 局限：当前 AI 技术不成熟，生成错误率高，多重迭代后仅 60% 勉强可用；
3. 最终方案：手动补写 4000 多字，覆盖 GBK 字符集，这类字使用频率低，不影响整体书法风格。

## 工具核心功能

支持导入手机拍摄的高精度书法图片（约 1/6 四尺对开）：

| 步骤 | 功能 | 说明 |
|------|------|------|
| 1. 切割布局 | 自动检测 + 手动调整 | 解决书法作品行列间距不均问题 |
| 2. 切割调整 | 逐字检查 | 删除噪点、错字、空白 |
| 3. 缩放校正 | 统一像素、居中排版 | 生成标准尺寸单字图 |
| 4. 标注出图 | 批量/手动标注、繁简转换 | 支持繁简混合模式、CJK 扩展区字符 |
| 5. 导出命名 | FontLab 标准命名 | BMP 字符 `uniXXXX`，扩展区字符 `uXXXXX` |

### 步骤 1：切割布局

![切割布局](docs/images/图一.png)

- 上传手机拍摄的书法图片
- 软件自动检测行列切割线
- 可手动拖动切割线调整位置，Shift+双击添加新切割线

### 步骤 2：切割调整

![切割调整](docs/images/图二.png)

- 逐字检查切割结果
- 删除噪点、错字、空白切片

### 步骤 3：缩放校正

![缩放校正](docs/images/图三.png)

- 统一字符像素尺寸
- 自动居中排版

### 步骤 4：标注出图

![标注出图](docs/images/图四.png)

- 三种标注模式：繁简混合、以简为主、以繁为主
- 支持批量标注和手动逐字标注
- 自动 OCR 识别辅助标注
- 导出后自动清理中间文件

### 步骤 5：导出

![导出结果](docs/images/图五.png)

- 输出 FontLab 标准命名的字符图片
- 重复字符自动添加后缀区分

## 快速开始

### 方式一：独立运行版（推荐）

从 [GitHub Release](https://github.com/gaudi1209/gaudi-font-preprocess/releases) 下载最新的 `高迪书法字库预处理工具.zip`，解压后双击 `启动.bat` 即可使用，无需安装 Python 及任何依赖。

### 方式二：从源码运行

```bash
# 克隆仓库
git clone https://github.com/gaudi1209/gaudi-font-preprocess.git
cd gaudi-font-preprocess

# 安装依赖
pip install -r requirements.txt

# 启动
python app.py
```

启动后浏览器打开 `http://localhost:7500`。

## 技术栈

- **后端**：Python + Flask
- **图像处理**：OpenCV + Pillow
- **OCR**：EasyOCR
- **繁简转换**：OpenCC
